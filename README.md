# 💰 Calculadora de Gorjeta

Uma aplicação web simples e intuitiva para calcular gorjetas e dividir a conta entre múltiplas pessoas.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da aplicação
- **CSS3**: Estilização com gradientes e animações suaves
- **JavaScript**: Lógica de cálculo e atualização de valores em tempo real

## 🚀 Como Usar

1. **Clone ou baixe o repositório**
2. **Abra o arquivo `index.html`** em seu navegador
3. **Digite o valor da conta** no campo de entrada
4. **Ajuste a porcentagem de gorjeta** usando o controle deslizante
5. **Defina o número de pessoas** para dividir a conta
6. **Visualize os valores calculados** em tempo real

## 📊 Como Funciona

A aplicação realiza os seguintes cálculos:

- **Valor da Gorjeta** = Valor da Conta × (Porcentagem / 100)
- **Total com Gorjeta** = Valor da Conta + Valor da Gorjeta
- **Total por Pessoa** = Total com Gorjeta / Número de Pessoas

Todos os valores são formatados em reais (R$) com duas casas decimais.

## 📝 Exemplos de Uso

### Exemplo 1: Dividir conta com amigos
- Conta: R$ 100,00
- Gorjeta: 15%
- Pessoas: 4
- **Resultado**: R$ 28,75 por pessoa

### Exemplo 2: Sem divisão
- Conta: R$ 50,00
- Gorjeta: 20%
- Pessoas: 1
- **Resultado**: R$ 60,00 no total
